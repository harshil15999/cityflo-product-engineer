    Coding rules
    
  
    Each message gets one primary code (the issue needing action soonest), up to three secondary codes and any modifiers. Messages are grouped by the primary code.
    
  
      
  
      Modifiers
      
  
      Context, not issues. Solid border: chosen by the model (or a human). Dotted border: set by code from the batch.
      
  
      
  
      Event codes
      
  
      Built like a procedure code (ICD-10-PCS): 7 positions, one character each, every position one axis, together describing exactly what happened. Each category code gets one, documented by the same quote. Z means not stated or not applicable: the tool never guesses. Positions 2 to 7 never use I or O. Code sets position 5 from the message time and the single, repeat and corroborated qualifiers from the batch.
